# Anharmonic Labs frontend

The files in this directory, together with the repository `index.html`, are
the public static browser frontend. They are licensed under GNU GPLv3; see
[`COPYING`](COPYING) and [`LICENSE-GPL-3.0.txt`](LICENSE-GPL-3.0.txt).

This frontend is a deterministic numerical browser simulator and visualization
layer. It does not contain or relicense the Python research package, native
kernels, external SDKs, credentials, or hardware protocols.
