# Research readiness and open evidence

Status: implementation-grounded checklist, 2026-09-13.

This document maps the evidence required for a stronger research claim to what
is actually present in this repository. A `partial` or `missing` item is an
open research task, not an implied result.

| Requirement | Status | Evidence or gap |
|---|---|---|
| Mathematical operator note | `partial` | [Mathematical definition](mathematical_definition.md), canonical source hashes, and [technical comparison](technical_novelty_and_method_comparison.md) define the finite operator, orientation, and limitations. A dedicated eigenstructure/conditioning note for increasing dimensions is still needed. |
| Non-generic gate synthesis | `missing` | Current Qiskit circuit construction embeds the finite matrix as a generic `UnitaryGate`. Transpiler counts demonstrate cost but are not a structured synthesis algorithm. No efficient fixed-basis or Clifford+T decomposition is claimed. |
| Independent reference checks | `met for tested scope` | Native NumPy, Qiskit, and optional Cirq/Qulacs/Stim differential tests exist. Browser parity is generated by `experiments/run_browser_parity.py`; seeds and phase-aligned amplitude/probability metrics are recorded. |
| Increasing-size benchmark table | `partial` | `run_fair_benchmarks.py` and `run_polar_vs_qft_suite.py` record timing and synthesis metrics, but the active comparison is small (`N=2,4,8` for Polar/QFT). A publication-grade increasing-$n$ table with fixed hardware/software and memory sampling remains open. |
| Fresh-environment reruns and CI | `partial` | CI installs declared extras and runs unit, differential, structured, native, and reproducibility smoke tests. Browser tests and browser parity are now included in CI. Dependency ranges are declared in `pyproject.toml`; a lockfile or fully pinned requirements set is still needed for bit-for-bit environment recreation. |
| Hardware jobs and same-window baseline | `missing under active identity` | The IBM protocol is implemented and submission is manually gated, but current Anharmonic Labs evidence contains no active non-legacy job ID paired with a same-calibration QFT/task-equivalent baseline. Synthetic Aer noise is not hardware evidence. |

## Reproducible commands

From the repository root:

```bash
python -m pip install -e "./anharmonic-labs[dev,qiskit]"
cmake -S anharmonic-labs/native/structured_kernel -B anharmonic-labs/build/anharmonic-structured
cmake --build anharmonic-labs/build/anharmonic-structured --config Release
node --test anharmonic-labs/tests/web/*.test.mjs
python anharmonic-labs/experiments/run_browser_parity.py
python anharmonic-labs/experiments/run_differential_suite.py
python anharmonic-labs/experiments/run_mathematical_closure.py
python anharmonic-labs/experiments/run_structured_suite.py
python anharmonic-labs/experiments/run_fair_benchmarks.py
python anharmonic-labs/experiments/run_polar_vs_qft_suite.py
python anharmonic-labs/experiments/run_sparse_50_parity.py
```

Generated result JSON files include a commit, dirty-worktree flag, dependency
versions, seed, input hash, command, limitation, and SHA-256 sidecar. Results
must be regenerated in a clean worktree when used as release evidence; a dirty
flag means the record is diagnostic rather than a clean-release artifact.

## Interpretation rules

- Agreement with a reference simulator establishes implementation agreement,
  not physical quantum advantage.
- A generic unitary-gate transpilation establishes finite embeddability, not an
  efficient synthesis method.
- A compact sparse or structured representation establishes only the declared
  restricted-domain behavior, not arbitrary-state compression.
- A hardware claim requires a job ID, raw data, calibration interval, backend,
  shots, and a task-equivalent baseline collected under the same conditions.
